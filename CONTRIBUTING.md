# Contributing

Frostbite's source is public under the Functional Source License (FSL-1.1-ALv2, see `LICENSE`), so you can read it, run it and send changes.

- By sending a change (a pull request or a patch) you confirm that you wrote it or have the right to send it, and you license it to ADORORG
  and to everyone else under the same terms as the rest of the repository (`LICENSE`), including the Apache-2.0 licence it becomes after
  two years. Do not send code you do not have the right to share, or code under a licence that conflicts with this one.
- Artwork, audio, scene videos, the name and the logo are not part of the licence (see `NOTICE`). A change that adds some must say where it
  came from and under what terms, and we may ask you to assign or license it to us before we can merge it.
- Read the architecture rules in `README.md` first: files stay under 300 lines, every change has tests, and
  `pnpm ci:local` passes before a change is proposed.

This note is not a contributor licence agreement. If one is needed (for outside contributors to a public repository, it usually is), the
owner decides it and this file is updated with how to sign it.
